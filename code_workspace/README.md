# Code Workspace

Use this folder as your no-paste handoff area.

## If you can't paste code in chat
1. Put your files in `code_workspace/incoming/`.
2. Keep original filenames if possible.
3. Add a short note in `code_workspace/incoming/NOTES.md` with:
   - what each file is
   - what you want changed
   - any errors you are seeing

Then tell me: **"work from code_workspace/incoming"** and I can continue from there.

## Suggested structure
- `incoming/` → raw files you want me to read first
- `src/` → cleaned/organized code we create together
- `experiments/` → temporary notebooks/scripts
- `outputs/` → generated results
